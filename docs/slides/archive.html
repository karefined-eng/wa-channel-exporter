ZIP Manifest & Reconciliation
METRIC RECONCILIATION LOGIC
POSTS Distinguish between Observed, Included (date-filtered), and Excluded.
MEDIA Classify as Downloaded, Unavailable (expired), or Failed (error).
INTEGRITY Deterministic SHA-256 hashes for all successfully retrieved media files.
AUDIT Explicit manifest.json mapping every record to its local file or failure code.
The archive is designed for auditability. Never claim "complete" when the boundary was not reached or media failures remain unexplained.
