05 / History Strategy

Complete history capture is a controlled load loop.

STEP 01
Initialize Date Boundary
Set explicit From/Through dates (e.g., 1 August to Present). Capture the current viewport as the starting boundary.
STEP 02
Controlled Upward Traversal
Locate the scroll container. Trigger small upward increments and wait for DOM stabilization after each mutation.
STEP 03
Incremental Extraction
Extract, fingerprint, and deduplicate posts. Normalize human-readable dates into machine-readable ISO formats.
Boundary Conditions
Stop when the oldest observed post is strictly before the start boundary.
Report "Boundary Not Reached" if scrolling stops before the target date.
Handle ambiguous dates (e.g., "Yesterday") by pinning to the scan timestamp.
Safety Guardrails
Maximum iteration count to prevent infinite loops on DOM errors.
Unchanged-height threshold to detect end-of-history or loading stalls.
Explicit user cancellation to stop long-running historical scans.
