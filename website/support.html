Troubleshooting Quick Tips

  • WhatsApp Web Updated? Reload your WhatsApp Web tab to let the content script re-hook the latest DOM elements.
  • Channel Not Scrolling? Click once inside the channel message feed area so it gains focus before starting an automated scroll scan.
  • Large Media Collections: For channels with hundreds of photos/videos, keep your WhatsApp Web tab active to prevent Chrome from throttling background DOM reads.
