Support & Help Center

WA Channel Exporter is a local-first, read-only tool for exporting WhatsApp Channel content that is available in your WhatsApp Web session. This page explains the supported workflow, known limitations, and the information needed for a useful support request.

Quick Start

  1. Install WA Channel Exporter from the Chrome Web Store, or follow the development installation guide for an unpacked build.
  2. Open WhatsApp Web and open the Channel you are authorized to view.
  3. Open the extension side panel, confirm the detected Channel name, choose a date range, and select the export scope.
  4. Start the scan and keep the WhatsApp Web tab available until the scan finishes. Review the completion status and media report before relying on the archive.
  5. Open the downloaded ZIP archive and use index.html for offline browsing. The archive also includes structured formats such as Markdown, JSONL, and CSV.

Troubleshooting

“No Channel detected”

Confirm that a Channel—not a one-to-one chat or group—is open in WhatsApp Web. Reload the tab, wait for the Channel header and posts to appear, then reopen the side panel. You can also use the re-detect control and edit the Channel name before exporting.

“No posts in date range”

WhatsApp Web only exposes content that has loaded in the current session. Try the All Loaded preset, scroll the Channel to load more history, and run the scan again. The extension cannot recover deleted or unavailable posts.

Media is missing or marked unavailable

Some media may expire, fail to load, or be unavailable to the current WhatsApp Web session. Check media-report.json in the archive for the per-item status. A missing file does not prove that the media never existed.

The scan stops or the page does not scroll

Keep the WhatsApp Web tab open and active during large scans. Reload WhatsApp Web before retrying, close duplicate WhatsApp Web tabs, and avoid navigating away while the scan is running. If the problem began after a WhatsApp update, report it using the template below.

The download does not appear

Check Chrome’s download shelf and download settings, then confirm that the browser has not blocked multiple downloads. Retry with a smaller date range and verify that the extension has permission to download files.

Known Limitations

  • The extension works with WhatsApp Channels in WhatsApp Web. It is not a standard one-to-one or group chat exporter.
  • Results depend on what WhatsApp Web loads and makes available during the scan. Historical completeness is not guaranteed.
  • WhatsApp Web changes may temporarily affect Channel detection, scrolling, or media retrieval.
  • The extension is read-only. It does not send messages, bypass login, recover deleted posts, or guarantee that using a third-party tool will never trigger platform enforcement.
  • Exports are local archives. They are not automatically tamper-evident and do not guarantee legal admissibility or republication rights.

Bug Report Checklist

Include the following details so the issue can be reproduced:

  • Extension version and Chrome version.
  • Operating system and whether the extension came from the Chrome Web Store or an unpacked build.
  • The exact steps that led to the problem and the expected result.
  • Whether the issue affects all Channels or one Channel.
  • Any visible error text and whether reloading WhatsApp Web changes the result.
  • Relevant counts or status from manifest.json and media-report.json, with private content removed.

Do not attach phone numbers, login details, private messages, credentials, or unredacted Channel archives to a public issue.
