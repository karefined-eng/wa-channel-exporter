How to Install in 3 Simple Steps

  1. Download the extension .zip file using the button above.
  2. Open Chrome and navigate to chrome://extensions.
  3. Toggle on "Developer mode" in the top right corner, then simply drag and drop the downloaded .zip file into the window!

✓✓ The extension is now installed and ready to use on WhatsApp Web!

How to Download WhatsApp Channel Media and Assets

Downloading photos, videos, audio notes, and documents from a broadcast channel requires a dedicated media extraction pipeline because WhatsApp Web does not provide bulk media saving for the Updates feed. Standard methods force users to manually click and save individual images one at a time.

WA Channel Exporter automates this workflow directly inside your browser. By intercepting authenticated binary blob responses during an active scan, the extension retrieves original high-resolution files without compression artifacts. It systematically categorizes all recovered files into date-stamped subdirectories (media/YYYY-MM-DD/) alongside an exhaustive media-report.json integrity audit.

✓✓ Full Fidelity Archiving: Preserves original metadata, resolution, and audio fidelity with zero cloud transmission.
